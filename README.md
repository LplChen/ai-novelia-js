# 用AI写的绿站增强脚本

## Novelia 书单制作助手（Gemini 3 Pro写的）

- 在绿站的网络小说、文库小说、阅读历史、收藏夹页面抓取书籍列表信息，支持全选、反选、多选
- 支持多书单编辑、管理、效果预览
- 可勾选和排序抓取的信息项目（网络小说-日文原名+链接、中文名、标签tags、连载状态+话数；文库小说-中文名+链接）
- 操作面板支持自动跟随网站主题色，手动选择亮色或暗色

<br/>

## Novelia 网络小说黑名单助手（Claude 4.6 Sonnet写的）
- 在绿站的网络小说的搜索、详情页面添加“拉黑”按钮，拉黑的小说在搜索列表会被隐藏
- 右下角悬浮按钮可呼出黑名单管理面板，可移除黑名单小说
- 支持本地导入、导出黑名单数据
- 操作面板支持自动跟随网站主题色，手动选择亮色或暗色

<br/>

## LightNovel.jp 绿站文库搜索按钮（Gemini 3 Pro写的）
- 在LightNovel.jp的[发售列表](https://lightnovel.jp/publicationdate/)书籍标题后增加绿站文库搜索按钮
- 搜索时去掉了书名末尾的卷号后缀（对于书名中间的第*部或外传等字眼未作处理）

<br/>

## Novelia 文库刷新助手（Gemini 3 Pro写的）
- **>>> 【警告：请在未登录亚马逊账号的情况下使用，避免被封号】 <<<**
- 小窗口Worker自动刷新文库元数据。支持后台运行，自动翻页，可动态调整并发窗口数量。
